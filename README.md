# Sistema de Funcionários em Python

Projeto desenvolvido em Python com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO).

## Objetivo

Criar um sistema simples para gerenciamento de funcionários, gerentes e departamentos, aplicando conceitos fundamentais de orientação a objetos.

## Conceitos praticados

- Classes e objetos
- Atributos
- Métodos
- Método construtor `__init__`
- Encapsulamento
- Atributos privados
- `@property`
- Getters e setters
- Herança
- `super()`
- Sobrescrita de métodos
- Método `__str__`

## Estrutura do projeto

O sistema possui as seguintes classes:

### Funcionario

Representa um funcionário da empresa, contendo informações como:

- Nome
- Salário
- Matrícula

### Gerente

Herda características da classe `Funcionario` e adiciona informações específicas, como o setor de atuação.

### Departamento

Responsável por organizar e gerenciar os funcionários pertencentes a um determinado departamento.

## Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos
